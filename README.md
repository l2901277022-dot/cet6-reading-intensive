# 六级精读台

把六级 Section C 阅读原文、词汇联想、整套真题词频、段落译文、真题订正、交互式句法分析与听力精听放在同一个页面。阅读收录 2022—2026 年的 29 套试卷，共 58 篇；听力模块当前收录 2024 年 6 月第 2 套的 7 篇、25 题。

## 打开网站

**在线使用：[六级精读台](https://l2901277022-dot.github.io/cet6-reading-intensive/)**

电脑和手机均可通过浏览器直接打开，无需注册、登录 GitHub 或安装软件。把上面的网页链接发给朋友，对方即可使用；这个仓库页面用于查看文件和说明。

## 怎么用

1. **选择文章**：电脑在左侧“真题书架”选择年份、试卷和 Passage One／Two；手机先点顶部“选择试卷”。
2. **查看单词**：电脑把鼠标移到单词上，手机轻触单词，查看释义、词性、音标、语法词形、词汇联想、文中搭配与整卷词频。点击喇叭可朗读单词。
3. **查看译文**：点击每段末尾的“查看译文”，展开该段中文参考译文。
4. **分析句子**：点击一句后，在句法工作台点击不同颜色的语法片段，查看中文含义、结构类型、句法功能、内部拆解、规则、结构还原和类似例句。
5. **真题订正**：每篇文章顶部有“做本篇真题 · 5 题”入口。58 篇阅读各有五道原题，可分别查看题干与选项翻译、参考答案和解析。2024 年 6 月第 2 套 Passage One 有本站校订的详细逐项解析；其他篇目的定位与选项判断会在有核对资料时展示，并附来源链接。
6. **继续阅读**：用文章底部“上一篇”“下一篇”切换，或重新从书架选文章。
7. **练习听力**：点击顶部“听力”，打开[听力精听台](https://l2901277022-dot.github.io/cet6-reading-intensive/#listening)。播放完整录音，选择七篇中的一篇；“先做题”隐藏原文，“精听订正”显示原文和译文。每题可单独展开翻译、答案与逐项解析，并跳到原文定位。原文可切换“只看原文／中英对照／只看中文”；单段的播放按钮使用浏览器朗读英文。

切换文章后，网址会记录当前篇目；刷新不会跳到别篇。浏览器也会记住上次选择的文章，记录保存在本地，不会同步到其他设备。

## 资料说明

- 词频统计覆盖 29 套整卷的可见英语，包括写作题目、听力题干与选项、阅读 Section A/B/C；固定作答说明、答案和解析不计入。公开卷面没有听力录音全文，因此听力词频不含对话、短文和讲座原文；翻译题是中文材料，不计入英语词频。
- 大部分段落译文与句法分析由模型生成，供理解参考；2024 年 6 月第 2 套 Passage One 另有校订译文、重点词讲解、关键句说明及第 46—50 题订正。
- 58 篇阅读的原题与参考答案按[公开试卷及答案页](https://www.guojiya.cn/exam/)整理。正文、题干、选项和定位证据均按篇章语境重新翻译，并校验段落、题号和选项的对应关系。仅在英文题干、四个选项及答案都能与另一来源逐项匹配时，才加入该来源的定位句和选项判断；未匹配的篇目保留原题、答案和来源链接。
- 每篇文章顶部可查看原题来源、核对原文分段；书架底部“资料与统计口径”提供更多说明。
- 英汉词典数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)，对应许可见 [ECDICT-LICENSE.txt](./ECDICT-LICENSE.txt)。该许可适用于词典数据，不代表全部内容采用相同许可。
- 听力原文、题目、译文与解析依据[公开真题学习资料](https://english-exam.lazynote.cn/cet6/sections/listening/2024-06-2/)整理；[完整录音](https://www.eduaah.com/2026/10/924/)由外部网站提供，播放需联网。七篇切换用于查看对应的题目和原文，录音播放器目前提供整套音频。

## 文件与维护

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网页入口 |
| `styles.css` | 页面样式与手机布局 |
| `app.js` | 查词、译文、句法与切换文章等交互 |
| `review.js` / `review-data.json` / `reading-questions.json` | 58 篇阅读的原题、翻译与解析；目标篇的校订解析 |
| `grammar.js` / `grammar-data.json` | 连续语法分段与逐片段讲解 |
| `frequency-full.json` | 29 套整卷可见英语的词频与覆盖记录 |
| `corpus.json` | 阅读文章、词典、词频与分析数据 |
| `listening.js` / `listening.css` / `listening-data.json` | 听力题目、原文、译文、解析与交互 |
| `ECDICT-LICENSE.txt` | 词典数据许可 |
| `.nojekyll` | 让 GitHub Pages 直接提供静态文件 |

网站由 GitHub Pages 托管，发布来源为 `main` 分支根目录。更新相应文件并提交后，等待 Pages 部署完成即可生效；文件间的相对路径需保持有效。
